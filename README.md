# Кварта: лендинг небольшой обжарки кофе (Минск)

Одностраничный сайт для вымышленной обжарки «Кварта»: кто мы и почему важна свежесть (обжарка по четвергам, доставка по пятницам), кофе и цены, подписка, доставка и самовывоз, FAQ и форма заявки. Корзины и оплаты нет: заявку принимает менеджер и перезванивает.

Сайт: https://kvarta-coffee.netlify.app  
Ссылка на канал с уведомлениями о заявках: https://t.me/+70XjCJljkqYwMGY6

## Стек

Next.js 16 (App Router), React, Material UI с темой из токенов дизайна (шрифт Roboto), SQLite-файл (better-sqlite3), Vitest. Требуется Node 22.18 или новее.

## Запуск

```bash
npm ci
cp .env.example .env     # заполните значения, см. ниже
npm run dev              # разработка
npm run build            # сборка
node .next/standalone/server.js   # продакшен на своём сервере
npm test                 # тесты
npm run lint
```

На сервере с `output: 'standalone'` запускайте `node .next/standalone/server.js` (после `npm run build` скопируйте `.next/static` в `.next/standalone/.next/static`). Подробности: `docs/deploy-server.md`.

## Переменные окружения (`.env`, в git не попадает)

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather (секрет) |
| `TELEGRAM_CHAT_ID` | закрытый чат менеджера: сюда приходит заявка целиком (имя, телефон, комментарий, метки) |
| `TELEGRAM_CHANNEL_ID` | публичный канал: только анонимное уведомление «Новая заявка · тип · время» |
| `LEADS_DB_PATH` | путь к файлу базы на сервере, например `/data/leads.sqlite` (по умолчанию `./data/leads.sqlite`) |
| `NEXT_PUBLIC_SITE_URL` | адрес сайта; нужен при сборке для ссылок Open Graph, sitemap и canonical |

Если `TELEGRAM_CHAT_ID` не задан, имя и телефон нигде не доставляются, кроме файла базы. Идентификаторы чата и канала не должны совпадать: при совпадении уходит только анонимный пост.

## Как устроена заявка

`POST /api/lead`. Телефон только белорусский мобильный (+375 25/29/33/44), повторная заявка с тем же телефоном в течение 10 минут не создаёт вторую (ответ «дубликат»), двойной клик не создаёт дубль. Защита от ботов: скрытое поле, минимальное время заполнения, лимит 5 запросов с одного IP за 10 минут. Сохраняются UTM-метки, `yclid`, `ysclid`, `fbclid`, страница входа и источник. Сначала заявка записывается в базу, потом уходит уведомление в Telegram; сбой Telegram заявку не теряет.

## База данных

Одна SQLite-база в файле на сервере (режим WAL, `synchronous=FULL`, права 0600). Сторонних баз нет. Выгрузка, резервная копия и очистка: `npm run leads:export`, `npm run leads:backup`, `npm run leads:purge`. На Netlify и Vercel диск временный, поэтому постоянно хранить заявки там нельзя: см. `docs/netlify.md`.

## Допущения и что не доделано

- Заявки на пятничную доставку принимаются до среды 20:00, обжарка в четверг, доставка в пятницу.
- Стоимость доставки при заказе меньше 50 BYN называет менеджер по телефону.
- Номера, Instagram и текст политики конфиденциальности условные, текст политики нужно проверить юристу.
- Вместо фотографии в блоке «О нас» нарисованная заглушка: нужна фотография со свободной лицензией.
- Живая проверка отправки в закрытый чат менеджера не сделана (`TELEGRAM_CHAT_ID` не задан).
- Скорость: Lighthouse (мобильный) около 0,91 по производительности на более ранней сборке; после последних изменений замер не повторялся.
